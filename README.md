# GLP-1 CVOT Evidence Synthesis Engine

Self-contained, offline-capable browser engine for living evidence synthesis of
GLP-1 receptor-agonist cardiovascular-outcome trials (RapidMeta GLP-1 RA CVOT,
3-point MACE primary outcome). Open `index.html` in any modern browser — no
install, no server, no external dependencies required to compute.

Companion tool for the article **"GLP-1 CVOT Evidence Synthesis Engine"**
(Mahmood Ahmad & Yousuf Imran), *Gnosis*, Vol. 1 No. 2 (2025),
synthesis-medicine.org.

Live: https://mahmood726-cyber.github.io/glp1-cvot-engine/
